\# Ollama Kurulum ve İlk Test



\## Proje

Mühürlü Kapı — Orrin NPC yapay zekâ sistemi



\## Kurulum Bilgileri

\- İşletim sistemi: Windows

\- Ollama istemci sürümü: 0.18.2

\- Yerel sunucu: http://127.0.0.1:11434



\## Bilgisayarda Bulunan Modeller

\- tinyllama:latest

\- phi3:mini

\- llama3.1:8b



\## İlk Test



\*\*Kullanılan model:\*\* tinyllama:latest



\*\*Test komutu:\*\*

`ollama run tinyllama:latest`



\*\*Test mesajı:\*\*

Sen Orrin adında fantastik bir kapı bekçisisin. Oyuncu senden kapıyı açmanı istiyor. Türkçe ve tek cümleyle cevap ver.



\## Test Sonucu



\- Ollama sunucusu başarıyla çalıştırıldı.

\- Yerel API bağlantısı doğrulandı.

\- TinyLlama modeli cevap üretti.

\- Türkçe cevap kalitesi yetersiz bulundu.

\- Sonraki aşamada phi3:mini modeli test edilecek.



\*\*Genel durum:\*\* İlk bağlantı testi başarılı. NPC davranış ve JSON karar sistemi henüz geliştirilmedi.
